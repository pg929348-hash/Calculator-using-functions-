# 🧮 Simple Python Calculator ✨

A simple and cute command-line calculator made in Python! 💻
It does basic maths and saves your history 📝

## 🌟 Features
- ➕ Addition (+)
- ➖ Subtraction (-)
- ✖️ Multiplication (*)
- ➗ Division (/)
- 🚫 Handles divide by zero error
- 📜 Saves history of calculations
- 🔟 Allows 10 attempts
- 👋 Quit option

## 🧠 Code Structure
- `calculator()` -> 🧮 Does the main calculation
- `history` list -> 🗃️ Stores all your calculations
- `attempt` -> 🔢 Counts attempts (max 10)
- `try-except` -> 🛡️ Stops crash if you type text by mistake
